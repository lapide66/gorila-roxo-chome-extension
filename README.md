Gorila Roxo Extension
=====================

Extensão para Chrome/Chromium que oferece as funcionalidades do projeto Gorila Roxo.

Resumo
- Repositório: gorila-roxo-extension
- Branch atual: master (upstream origin/master já configurado)

Estrutura do Projeto
- manifest.json: configurações da extensão
- background.js / service worker: código de fundo (se aplicável)
- content_scripts: scripts injetados em páginas
- popup/toolbar: interface de usuário principal (se aplicável)
- assets/: ícones e recursos estáticos

Instalação e Execução Local
Pré-requisitos
- Google Chrome/Chromium
- Acesso a uma rede para dependências (se utilizado)

Como executar localmente
