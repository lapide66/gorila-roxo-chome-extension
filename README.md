# Gorila Roxo

Extensão Chrome que mostra um gorila roxo que aparece de forma aleatória na página quando você clica no ícone da extensão.

O gorila desaparece automaticamente após 10 segundos.

## Como usar

1. Abra `chrome://extensions`.
2. Ative `Modo do desenvolvedor`.
3. Clique em `Carregar sem compactação`.
4. Selecione a pasta `gorila-roxo-extension`.
